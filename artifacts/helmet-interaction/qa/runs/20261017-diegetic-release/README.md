# 实体 UI 版本发布证据

`current.json` 保留最终 731 项检查、38 个来源指纹、环境与未验证范围；`history-*` 为对应旧阶段的摘要和来源指纹，不能当作当前版本重跑。四份原报告留在本地原目录，没有改写；来源路径、原始 SHA-256 见 `sources.json`。发布副本仅删除包含无关旧文件清单的 dirty 字段及本地诊断图片路径，不改变检查、结果或原始源码哈希；旧阶段只发布摘要，完整当前检查保留。暂存字节与被测字节的行尾／新增Unity空字段空白对应见 `published-file-map.json`。

`font-summary.json` 保留保存字形、磁盘图集和原引用核对结果，删除本机绝对路径。`review-previews/` 是保存主场景的普通单眼相机审阅图，不是真实头显截图。当前结果为 Unity 2022.3.62f3c1 编辑器模拟输入；真实头显、Direct 实手可达性、性能、舒适度与本轮构建未验证。
