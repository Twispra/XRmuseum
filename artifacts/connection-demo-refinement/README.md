# 供气／通话设备与演示 R1

任务入口：[Issue #33](https://github.com/Twispra/XRmuseum/issues/33)。这是一套供组员审阅、继续精修的独立资产，尚未替换 Unity 里的供气／通话演示。

## 先看什么

- [设备全景](previews/01-equipment-overview.png)、[泵细节](previews/02-pump-detail.png)、[电话细节](previews/03-telephone-detail.png)、[泵背面](previews/04-pump-rear.png)：在 GitHub 直接查看。
- [交互演示 review.html](preview/review.html)：在 GitHub 点下载原文件，再用电脑浏览器打开。模型和六条音轨都内嵌在这一个文件里，约 49.6 MB；浏览器需要 WebGL。GitHub 文件页面本身不会执行 3D 演示。
- 如果直接打开受浏览器限制，在此目录运行 `python -m http.server 8771 --bind 127.0.0.1`，访问 `http://127.0.0.1:8771/preview/review.html`。这是本机服务，不是公开发布。
- 演示默认静音。选择 AIR / VOICE 后播放；拖动时间轴或点步骤会暂停，方便旋转观察。可展开泵的缸内结构，切换简体／繁体／英文及低动态路径。

本轮在本地 HTTP 下进行了浏览器测试。检查工具不允许 `file://`，因此未把“组员双击离线打开”写成已实测结果；文件结构已检查为内嵌资源，不依赖 CDN。

## 做了什么

| 内容 | 本轮交付 | 依据与界线 |
| --- | --- | --- |
| 水面供气泵 | 双手轮、共同曲轴、双缸、活塞连杆、木箱、冷却槽、仪表及出气连接；可看内部运动 | 1916 手册 Mark III 结构研究。仅缸径／行程按手册数值建模，外包尺寸和材质外观估算；仪表标 DEMO，无虚构压力刻度 |
| 水面电话 | 六个干电池、木箱、连接插口、单耳接听装置、独立发话器及电线 | 参考手册的装置配置；外形、局部尺寸和布线不是制造图纸复刻 |
| 潜水员电话示意件 | 帽形、两侧接听装置、单独发话器、膜片及保护格栅 | 独立结构解释件，帽形和安装布局含加工；没有声称它是 1944 头盔的准确内部组件 |
| AIR 动画 | 手轮与活塞共同运动 → 沿软管传输 → 背部空气接口响应 | 16 秒流程、0.65 转／秒和可见气流是教学时序，不是额定性能或真实气流速度 |
| VOICE 动画 | 水面发出 → 头盔接收 → 头盔回复 → 水面接收；发话膜片对应活动 | 信号包、颜色、3.2 秒传输及膜片幅度均为教学示意；不模拟真实电气电路或声波传播 |
| 声音 | 机械质感／清楚提示／低刺激三种方案，各含 AIR、VOICE 16 秒音轨 | 全部原创合成；非历史录音，无真实人声。低刺激是候选方案，未做用户舒适度验证 |

演示中的 Mark V 是已有 PR #32 模型的轻量观察副本，来源 commit 与哈希见 [context-provenance.json](qa/context-provenance.json)。1916 设备放在 1944 头盔旁边是解释性组合，**没有证据证明它们是一套实际配装**。原头盔文件未修改，这个副本也不是已验收的运行时 LOD。

## 文件与编辑入口

| 路径 | 用途 |
| --- | --- |
| `sources/equipment.blend` | 三套设备总源文件，含灯光与拍摄布局；几何、材料、动画可编辑，原始贴图已打包 |
| `sources/parts/*.blend` | 独立分件源文件，根节点在原点，方便单独认领 |
| `exports/*.glb`、`*.fbx` | 每套设备各一份导出；单位米。GLB 贴图内嵌，FBX 贴图嵌入，另有原始 PNG |
| `textures/` | 本轮生成的木材／金属 BaseColor、Roughness、Normal；没有复制第三方贴图 |
| `audio/` | 六条 48 kHz、单声道、16-bit PCM WAV 与音量／哈希记录 |
| `scripts/` | 生成来源、音轨、时间轴、浏览器构建及验证脚本；不能代替后来人工修改的源文件 |
| `references/` | 可查来源、事实／估算参数及研究记录；不分发原手册或馆藏图片 |
| `qa/` | 源几何审计、导出回读、浏览器截图与本轮检查结果 |

总源文件里的根节点有拍摄位移，`90_STUDIO_NOT_EXPORTED` 是灯光和展台。独立分件与导出根节点为原点。Blender：Z 向上、-Y 为正面；导出：Y 向上、+Z 为正面。若重新导出，选根节点及其所有后代，排除拍摄集合。

泵循环为 30 fps、源帧 1–61，2 秒一圈。GLB 将 9 个运动节点导为 9 个 clip，**必须一起播放**，不是只选第一个；电话／潜水员示意件各有 1 个膜片 clip。浏览器已统一控制它们。FBX 回读的 take 起点是帧 2，检查按实际起点对齐秒数。以后导入 Unity 还需核对 clip 范围与循环设置。

## 验证与尚待完成

已核对源文件的 61 帧运动、184.15 mm 活塞行程、连杆端点；三套设备的 GLB／FBX 均能回读，几何三角形数及包围尺寸一致，五个时刻的运动节点姿态与源文件相符。设备共 431 个网格、95,452 个三角形；总几何没有非流形边。装饰文字含 10 个面积小于 `1e-12 m²` 的微小面，不是机械结构；后续可改为贴花。

浏览器检查包括暂停冻结、重播、拖动、复位、AIR／VOICE 切换、通信回复方向、三语、低动态和三种声音启停。音轨无数字削波；没有声称已人工试听、完成用户研究或保证实际耳机声压。

**尚待：**组员历史与造型审阅、声音试听选择、降低网格和材质成本、Unity 导入与原功能适配、真实设备性能与用户测试。当前较多分件适合编辑审阅，不宜直接作为最终 VR 性能方案。结果详见 [qa/validation.md](qa/validation.md)，接手步骤见 [协作与接入说明](collaboration.zh-CN.md)。
