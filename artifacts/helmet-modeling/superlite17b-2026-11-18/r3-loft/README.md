## 新几何怎样生成

`loft_geometry.py`从7×16参数化控制点生成新面，点的语义沿截面一致；纵向/周向用Catmull插值。112点不是112个独立实物测量点。只复用旧对象名与材质，未读取旧壳顶点做投影/拉伸。前面以独立倾斜平面构造真正窗口开口，下部切出颈口；薄壁只封壳壁边缘，不封住窗口/颈口。

先整体侧廓，再窗面、宽浅颞部内收、裙边、顶部肩部，逐轮保存控制参数。窄裙边外挤和较厚内壁导致自交的试验被舍弃；最后修正前窗周肩中心、合并切口极近点、避免内壁拐角翻折，显示壁厚估计改为0.8mm。**0.8mm不是实物复合壳厚度，也没有用于安全或制造结论。**

实际保留壳体4774顶点、9548三角面，闭合流形、单连通、零面积与所检非相邻自交候选为0。全盔仍146网格、66844三角面。只改变外壳，其余145个对象的几何/UV/变换/材质等指纹与备份一致。

但新壳与32个保留部件仍存在表面交叠候选，不能称总装无穿插。窗口压圈/22个螺钉槽件、下口原O形圈与颈封及后部件都未完成新接口。自身壳面检查干净不等于装配完成。
