# 照片头盔：外观精修第二稿

这是基于 [PR #28 第一版照片研究模型](../photo-study/README.md) 的**独立改进稿**，参考小组提供的同一件头盔前四张照片。第一版源文件、导出和 Unity 现用模型均未覆盖。本件的型号、实物尺寸、隐藏结构仍未证实；它不是 Mark V，也不是已完成的三年代展品模型。

## 这次能看见的改变

| 部位 | 第一稿 | 第二稿 | 依据与限制 |
| --- | --- | --- | --- |
| 外壳与胸甲 | 亮金色、整体较均匀 | 更深的旧铜/黄铜色与较粗糙表面 | 照片 01–04 的视觉印象；不是材质检测或照片贴图 |
| 前窗 | 较亮的前框与灰白窗面 | 加深固定框、内侧垫圈、嵌入式深色窗面和金属小圆结构 | 照片 01；窗体真实材料和透光率仍待核实 |
| 胸甲 | 空白铭牌、均布小螺母 | 给空白铭牌加凸起边缘，突出三个前缘紧固件 | 照片 01；铭牌字样、准确数量与位置不重建 |
| 侧面/背面 | 已有格栅和弯管 | 保留原有外形 | 照片 02–04 看不清接口功能，不编造机械构造 |

模型文件为 [整体 GLB](exports/photo-helmet-refined-v2.glb)。可在第一稿的 [离线审阅器](../photo-study/preview/review.html) 点击“选择 GLB”载入；浏览器直接打开 HTML 时也可选择本文件。`scripts/refine_photo_helmet.py` 是这次修改的可编辑、可重建来源，输入为第一稿的 GLB；需要先在本地将第一稿的 Git LFS 文件展开，再安装 [脚本依赖](scripts/requirements.txt) 后运行脚本。没有生成新的 `.blend`：本机 Blender 4.5.14 的窗口虽能打开，但无法完成后续编辑，命令行版本在显卡初始化时崩溃。组员可用 Blender 导入本 GLB 继续人工精修，并另存独立 `.blend`，不要覆盖第一稿源文件。

## 检查与未完成

- 已在本机用 GLB 回读确认 118 个几何节点、121,344 个三角形、有限坐标；详见 [检查结果](qa/export-readback.json)。第一稿为 103 个节点、113,976 个三角形，增加的几何主要为前框、窗面背衬、铭牌和前缘紧固件。
- 已在本地浏览器载入并检查正面及侧面显示；视觉细节仍需组员和原照片并排审阅，尤其是前窗较亮的环形表面、胸甲比例和侧窗几何。
- 尚未验证 Blender 中的可编辑源文件、FBX 导出、Unity 导入、材质透明排序、LOD/性能、头显效果或实际尺寸。因此此稿仍是**精修过程中的审阅资产**，不能直接接入主场景。
- 原照片未提交、未嵌入纹理；未辨认的铭牌文字保持空白。

合并顺序：此分支以 PR #28 的照片研究分支为基础，先审阅第二稿，再由模型协作负责人按 [Issue #25](https://github.com/Twispra/XRmuseum/issues/25) 的安排汇总。不要直接把此件当作正式展品合入 `main`。
