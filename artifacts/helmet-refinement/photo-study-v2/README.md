# 照片头盔：外观精修第二稿（可审阅版本）

这是基于 [PR #28 第一版照片研究模型](../photo-study/README.md) 的**独立改进稿**，参考小组提供的同一件头盔前四张照片。第一版源文件、导出和 Unity 现用模型均未覆盖。本件的型号、实物尺寸、隐藏结构仍未证实；它不是 Mark V，也不是已完成的三年代展品模型。“可审阅”指已完成文件检查和外观对照，**不等于历史考证或 Unity 交付已完成**。

## 这次能看见的改变

| 部位 | 第一稿 | 第二稿 | 依据与限制 |
| --- | --- | --- | --- |
| 外壳与胸甲 | 壳体偏灰、胸甲较浅 | 保留暖金属色，胸甲向下延伸；圆顶、前窗、胸甲的层次更接近照片 | 照片 01–04 的视觉观察；不代表金属成分或实测尺寸 |
| 前窗 | 外环约为壳体宽度的 71%，窗面偏灰白 | 外环约 61%，加深固定框、内侧垫圈与四个可见窗面的背衬 | 照片 01；比例为照片投影估计，真实透明度仍待核实 |
| 铭牌与胸甲紧固件 | 已有空白铭牌和周边螺母 | 保留原有件；撤掉上一轮尝试中位置不贴合的重复铭牌与三颗悬空紧固件 | 铭牌文字及紧固件真实数量未确认，不自行补写 |
| 侧面/背面 | 侧窗偏蓝灰，已有格栅和弯管 | 侧窗改为暖灰色；格栅、弯管和未知机械结构保留 | 照片 02–04；功能不作推断 |

模型文件为 [整体 GLB](exports/photo-helmet-refined-v2.glb)。可在第一稿的 [离线审阅器](../photo-study/preview/review.html) 点击“选择 GLB”载入；浏览器直接打开 HTML 时也可选择本文件。`scripts/refine_photo_helmet.py` 是这次修改的可编辑、可重建来源，输入为第一稿的 GLB；需要先在本地将第一稿的 Git LFS 文件展开，再安装 [脚本依赖](scripts/requirements.txt) 后运行脚本。没有生成新的 `.blend`：本机 Blender 4.5.14 的窗口虽能打开，但无法完成后续编辑，命令行版本在显卡初始化时崩溃。组员可用 Blender 导入本 GLB 继续人工精修，并另存独立 `.blend`，不要覆盖第一稿源文件。

## 检查与未完成

- 已在本机用 GLB 回读确认 110 个几何节点、117,304 个三角形、有限坐标；详见 [检查结果](qa/export-readback.json)。第一稿为 103 个节点、113,976 个三角形；新增的 7 个几何节点是前框/密封层与四个窗面背衬，没有重复铭牌和悬空紧固件。
- 已用相同的正面/侧面投影并排检查第一稿和第二稿，也与照片 01–04 对照。确认前窗相对盔壳收窄、胸甲可见深度增加、侧窗不再黑成空洞。照片有透视、遮挡和光照差异，不能据此断言所有尺寸准确。
- 尚未验证 Blender 中的可编辑源文件、FBX 导出、Unity 导入、材质透明排序、LOD/性能、头显效果或实际尺寸。因此此稿仍是**精修过程中的审阅资产**，不能直接接入主场景。
- 原照片未提交、未嵌入纹理；未辨认的铭牌文字保持空白。两侧吊索与外部展示链条属于展柜支撑，不并入头盔模型。

合并顺序：此分支以 PR #28 的照片研究分支为基础，先审阅第二稿，再由模型协作负责人按 [Issue #25](https://github.com/Twispra/XRmuseum/issues/25) 的安排汇总。不要直接把此件当作正式展品合入 `main`。
