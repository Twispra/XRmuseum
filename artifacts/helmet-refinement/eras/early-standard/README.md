# 早期头盔研究候选

关联 [Issue #25](https://github.com/Twispra/XRmuseum/issues/25)。目前只有[馆藏来源与建模边界](references/research-v1.zh-CN.md)及[机器可读参数首版](references/parameters-v1.json)；**没有精细模型、贴图、导出或 Unity 接入**。

候选参照为 Science Museum Group 馆藏 `1881-47`（1839 年封闭式潜水头盔及胸板）。小组需先确认是否采用同一件实物，再由建模负责人补足多视角、局部尺寸、分件和预览。未知值不能按 Mark V 或其他时期资产套用。

用户另提供香港海事博物馆一顶**1988 年在中国制造**的头盔近照。[前四张照片](references/photos/README.md)已获拍摄组员同意用于本小组项目，并随本资料提交；仅供讨论金属外壳、圆形观察组件与胸板等**视觉语言**。它不是 1839 年藏品，不能把照片中的部件、尺寸、重量或用途写成早期头盔史实。区分方法见[研究说明](references/research-v1.zh-CN.md)。

本轮资料来源、核对与限制见[活动记录](../../../../docs/activity/2026-10-12-early-helmet-research.md)。
