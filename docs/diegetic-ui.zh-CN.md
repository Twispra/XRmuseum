## 在主场景体验

打开 `MuseumVR` 工程，使用 Unity 2022.3.62f3c1，运行 `Assets/Museum/Scenes/MuseumStart.unity`。新模块在这一个主场景中使用现有模型、供气及通信演示，不需要进入独立演示场景。

无头显时，先点击 Game，切英文输入；T / Y 选择左手或右手，G 是当前项目的选择键。对准 UI 后按 G 并松开完成点击；按住 G，再通过模拟手的位置变化调整模型或切面。鼠标左键是模拟扳机，不是这些 XRI Select 控件的选择键。沿用模拟器的 WASD / QE 移动当前选中的设备，右键调整视角；查看模拟器提示确认当前控制的是手而不是 HMD。

## 操作规则

| 入口 | 操作 |
| --- | --- |
| 头盔外壳（没有独立旋转按钮） | 从外壳空白区域按住并拖动，起步有小幅容差。以按住时用户看到的方向为准：手向右，眼前表面跟着向右转；向上也同理。弧线拖动可滚转，前后伸手不产生旋转。松手停住，重新按住不跳变。模型中心固定，不平移、不抛掷。 |
| 前窗玻璃本身 | 没有常驻按钮。手靠近或射线指向实际前窗时显示“点击打开前窗”；打开后提示变为“点击关闭前窗”。点击位置随玻璃移动。原有前窗讲解热点仍可单独触发。 |
| 展台左侧固定剖面图标 | 按下出现选中反馈，松开确认进入剖面，再次点击恢复外观。入口不随头盔旋转。 |
| 固定短轨道上的切面滑块 | 剖面开启后出现。按住滑块沿可见轨道左右移动，滑块与手沿轨道的位移一致，系统换算切面位置。移动头盔不改变轨道方向；手向轨道外或前后移动不改变切面；转手腕不旋转切面。 |
| Air / 供气与 Voice / 通话 | 在对应部件附近点击展开模型并播放。再点同一入口收起；选择另一种演示会关闭当前演示。播放结束后模型保留，关闭后重开从头播放。 |
| 展台年代按钮 | 上一年代／下一年代。切换后前窗、剖面与演示关闭，模型恢复正面。 |
| Close demo / 关闭演示 | 供气或通话展开后，在展台固定位置出现，也可通过原部件入口再次点击关闭。 |
| Reset / 复位 | 当前模型恢复初始朝向，关闭前窗、剖面和演示，重置切面参数。保留当前年代及语言、声音、减少动画、提示偏好。 |
| Show hints / 显示操作提示 | 显示简短就地提示，再点隐藏。 |
| 演示设备本体 | 供气或通信展开后，直接按住设备表面并移动手来旋转，与头盔使用同一映射。中心固定、松手停止；设备不跟随视角或头盔转动，机械动画继续。关闭后重开恢复初始摆放。 |
| Settings / 设置 | 在展台固定位置展开三语、降低视角／恢复高度／升高视角、声音、减少动画、提示常显与重置视角。每次升降 5 cm，可调范围为初始跟踪高度上下各 50 cm；会话内保留，退出运行后不保存。 |
| About / 展品说明 | 展台固定位置展示模型简化边界，再点收起。 |

UI 默认较淡。手接近或射线悬停时平滑显现；操作中保持清楚，离开后延迟渐隐。透明度不改变命中范围。station Inspector 中可调整 idleOpacity（默认 .22）、handRevealDistance（默认 .18 米）和 fadeOutDelay（默认 .65 秒）；这些是原型参数，不是人体工学实测标准。已展开演示的关闭入口保持清晰。剖面图标和轨道滑块的名称在靠近或指向时出现，闲置时只留淡图形。旋转的小控制点附在实际命中处，文字单独放在模型边缘，没有悬浮旋转按钮。设置中的提示常显可让其他当前可用入口保持可见；前窗和旋转提示仍只在靠近或指向时出现，不恢复常驻按钮。

原三处部件讲解热点的触发位置和高亮表现沿用主线；讲解卡固定到展台右侧，避开按钮。学习回顾、重新参观、旧观察／探索导航不再作为访客入口。头盔内构造仍属于展示模型，SuperLite 的前窗侧开仍是博物馆观察演示，不能当作真实维修动作。

## 接手修改

新代码位于 `Assets/Museum/Features/DiegeticUI/`。`HelmetDiegeticStation` 负责位置、命令、互斥和旧界面的启停；`HelmetPhysicalControl` 只负责显现反馈；`HelmetGestureInteractable` 负责用户视角下的位置驱动旋转和切面平移；`HelmetControlSymbol` 用三维线条构建剖面和滑块图形，与文字一起渐隐；旧旋转图标的构建代码保留，但主场景不再生成它；`HelmetViewRecoveryGuard` 在 F11 改变 XR Origin 前结束手势，避免把视角回中当作手的运动。

`MuseumStart` 增加一个配置好的 station 组件。运行时构建操作标记，禁用旧跟随面板与旧自由拿放交互，原 Prefab、XR 输入与模型源文件保持原有版本。禁用 station 后可恢复旧入口；这用于接手排查，不是访客设置。

所有新文字登记在 `MuseumTranslations.json`，保存的 LocalizationTable 和静态字体同步更新。后续按 [三语接入说明](localization-authoring.zh-CN.md) 修改，不在回调里直接写中文／英文 `.text`。新增中文字体仍沿用原 Noto OFL 来源及资产 GUID。

`Museum.Diegetic.Editor.HelmetDiegeticValidation.RunBatch` 在保存的主场景执行 API、模拟 XR 输入、三语和布局检查，输出独立 `artifacts/helmet-interaction/qa/runs/` 目录。具体通过结果和当前证据链接见 [本轮活动](activity/2026-10-14-diegetic-single-hand-ui.md)。真实头显的单手可达性、双眼文字可读性、舒适度和可执行构建需要分别验证。

## 2026-10-16 调整注意

旋转使用按住时固定的观察坐标和虚拟球面；每次从中性起点开始，防止接触点位于头盔侧面时出现第一下方向偏差。弧线拖动产生滚转属于交互映射，不是实际物理仿真。增益 300 度／米是可调原型参数，尚未做真实用户校准。

前窗复用 RefinedHelmetBinding 随年代和铰链维护的原 BoxCollider；新目标注册时不把这个碰撞体再分给整盔旋转。禁用模块后先注销新目标，再恢复旧交互。不要在前窗处重新添加不可见的悬浮按钮。

本轮基于最新 main 重新安装新增 station、合并新文案并保留已有静态字形，未重建原型。原有知识热点位置不动；眼前实际玻璃是开合入口，原知识圆点仍是讲解入口。详细验证结果见本轮活动记录，未提交或推送。

新 UI 的 Direct 悬停与初次选择使用已注册物理手的固定开掌包络及既有遮挡检查；宽查询球内出现候选不等于手已接触，掌心也不必穿进模型才可选择。按钮松手确认、移开取消及部件优先级采用同一接触判定。没有物理手绑定的旧 Direct 入口仍保留 5.5 cm 初次接触距离。视觉提示仍可在 18 cm 处出现；已经按住的手势允许手离开命中区继续控制。这些均为待体验调整的原型参数。过滤不改变旧知识热点的触发原点。前窗开／关提示按动画目标状态更新，连续点击时不会提示相反动作。

本轮 479 项检查及具体修复见 [2026-10-16 活动](activity/2026-10-16-diegetic-icons-view-rotation.md)。开合控制器仅增加只读 `WindowTargetOpen`，供本模块在动画中显示下一次点击动作。

## 2026-10-16 第二轮：稳定入口、滑轨与确认反馈

按钮与拖动采用不同确认方式：普通开关按下时只显示压下／选中状态，松开且仍指向同一目标才确认；按住后明显移开则取消，必须松手后才能选择其他目标。旋转与切面是按住移动，松手即停。取消、F11、换年代和复位不会把释放误当成一次点击。

外壳指向时出现局部控制点和轻微材质反馈，按住时控制点加粗并变色，文字从“按住并移动手来旋转”变为“移动手来旋转／松手停止”。前窗、原讲解热点和其他部件的操作优先于外壳旋转。射线只响应实际最前方的新目标，不让藏在头盔后方的入口抢占操作。

剖面图标和轨道固定在展台左侧。轨道半行程为 0.15 米，映射到当前年代模型的 SectionRange；这是原型操作参数，不是头盔实物尺寸。轨道两端用颜色表示达到限位；设置展开时操作区暂时收起，设置关闭后恢复原位置，避免两块固定 UI 重叠。供气／通话仍在真实接口处触发；展台额外提供“关闭演示”，用于接口转到背面后的收起操作。

`HelmetPhysicalControl` 现在处理有效释放、取消与悬停／按住／确认反馈，视觉下压不移动碰撞体。`HelmetDiegeticStation` 负责取消整组已按住的操作和优先级；`HelmetGestureInteractable.ConfigureSectionRail` 配置轨道，主场景使用轨道映射，孤立旧调用可继续用原切面法向投影。原开合、演示、热点、语言及复位引擎继续使用。

主场景内部仍以 `Command.Rotate` 保存本体交互目标与提示，它不是访客按钮。该目标只注册原有头盔碰撞体，自己的旧图形／碰撞体均关闭；后续修改不要因为枚举里有 Rotate 就重新生成旋转按钮。外壳的 4 mm 起步容差只用于滤掉抓取开始的小幅抖动，不要求用户先等待固定长按时间。

## 2026-10-17：视角高度与可旋转演示设备

高度调整是访客的观看偏好，不校准或移动真实地面。`VisitorViewHeight` 在现有 Camera Offset 下插入临时包装节点，将相机和手柄一起沿世界竖直方向偏移；不改 CameraYOffset、跟踪模式、TrackedPoseDriver 的局部姿态或展台坐标。5 cm 步长、±50 cm 范围是可调整的原型参数。到达上下限时按钮显示“已到高度限制”。F11／重置视角和展品复位均保留已选高度，“恢复高度”单独清除偏移。调整前结束正在进行的拖动，防止把视角改变误算成手的旋转运动。

供气泵、通信设备展开时按展台原始朝向摆在头盔旁边；模型不再根据每帧的相机朝向重排。只有说明文字朝向观察者。设备表面出现与头盔相同的就地提示和抓取反馈，不另设旋转按钮；按住时记录观察方向，左右／上下移动改变角度，纵深伸手不转动模型，松手保持当前角度。设备既不平移，也不跟随头盔转动；关闭或换演示后重开恢复默认角度。

`HelmetDiegeticEquipment.cs` 为 Station 的分部文件，负责设备命中区、互斥及反馈。`HelmetConnectionDemonstration.EquipmentExhibits` 提供显示根、静态几何中心和可见网格；`HelmetGestureInteractable.ConfigureEquipment` 复用整盔旋转算法。精细设备的展示根位于 FBX 动画根之外，机械采样不会覆盖访客角度；软管／通信线持续读取旋转后的实际接口。`RefinedConnectionEquipment.Position` 只在演示展开时调用，后续不要重新放回每帧更新。

命中代理选择主要表面，省略最大可见尺寸小于 18 mm 的细螺丝、刻度等独立碰撞盒，但可见网格保留。这个尺寸只是原型优化参数；保留最大的网格作为小设备的选择后备。碰撞代理随各自部件层级运动，不把设备与头盔之间的空白区域包进同一大盒。高亮只在状态改变时写入，保留原演示的注意力属性；隐藏或停用模块后恢复原材质状态。真实 VR 的性能和舒适度仍需另外验证。

交接时要同时保留 `HelmetConnectionDemonstration.cs`、`RefinedConnectionEquipment.cs`、DiegeticUI 文件及三语表／字体。不要把外层展示根拿掉，不要令摄像机 Billboard 作用到设备本身。新命令取消已按住的设备后，必须松手再选其他物体；这与原头盔／切面一致。

## 2026-10-17 追加：旋转精细控制与近距提示

头盔与演示设备仍使用同一按住移动手势，固定几何中心、不平移。原先 4 mm 起步容差之后，新增持续的位置滞回：手在很小范围抖动时不立即改变角度，慢慢积累的移动仍会转动模型。低速移动转得更细，较快移动恢复原速度。算法只改变当前采样的转角，不保存待完成的旋转；静止不补转，松手立即停，取消／重新按住会清空滤波历史。剖面滑轨仍按原位移映射，不使用旋转过滤。

默认参数：持续容差 1.2 mm；慢速增益 0.35 倍；速度不高于 0.02 m/s 时用慢速增益，不低于 0.22 m/s 时恢复正常，之间平滑过渡，速度估计响应 45 ms。它们是可调原型设置，没有经过用户或真实控制器校准；不要写成老年用户的生理阈值。虚拟滚动球的几何半径保持原值，避免变速时连旋转方向也改变。

靠近模型观察时，控制点缩小，操作文字限制视角宽度。优先把文字放到模型侧缘；若近得看不全模型，就在视野上侧或侧缘选一个能完整看见的位置，初始预留 5% 视野边距，避开选中点和模型中心。文字四角还要处于近裁剪面外和目标表面前，避免放到模型背后。连续操作期间位置固定；抓取点仍随被选表面移动，近距时用细引线联系文字与抓取点。转动或换观察角度后，如果文字会挡住正在看的部位、跨到文字后侧或已没有可见空间，暂时收起文字及引线，保留小控制点。退出这次交互后再选，会按新视角重新定位。

访客实际转动至少 5° 后，本次运行的重复悬停提示缩成“按住旋转”，按住尚未移动时显示“移动旋转”；正在转动仍显示“松手停止”。设置中开启“提示常显”会恢复完整操作文字，但不取消近距避让、不让前窗或本体出现常驻按钮。默认近距范围 45 cm（退出滞回 5 cm）、文字最大视角宽度 18°及学习角度 5°均是原型参数。`HelmetRotationHint` 只管理视觉，不带碰撞体，不改变命中范围或点击规则。

三语短提示登记在 JSON 和保存表。字符清单未增加，原有静态 SDF 已覆盖全部所需字符，字体二进制与 GUID 不变。修改已有字符范围内的文案可运行 `HelmetDiegeticSetup.RefreshTextBatch` 同步表，不重写主场景；出现新字符仍须按三语接入说明检查并维护字体。
