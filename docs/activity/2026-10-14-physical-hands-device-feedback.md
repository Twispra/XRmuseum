## 反馈及证据范围

用户在当前对话报告头显已连接，要求直接协助电脑调试。设备日志显示 Meta Quest 3、Virtual Desktop / VDXR；Player 日志的 Managed 路径指向 `E:/XRmuseum/Builds/Windows/physical-hands-final-20261014-1531/MuseumVR_Data/Managed`，确认启动了首个新手模块候选。该构建的实际源码版本是 `09b9adfecf21a9ab6f8c261b72a0525c6d768d2e`，不是原目录中打开的旧 Unity 场景。原 Unity 编辑器处于停止播放状态。

用户报告两项异常：

- 近距抓握没有预期的贴附感，可见手与模型之间有空隙，物体难拿、难操控。用户以 Alyx 的抓握体验说明预期；这不是对 Valve 算法的实现要求或许可声明。
- 前后移动发生向后卡顿、离开视觉边界。随后明确操作的是**左手柄摇杆**。

这些是一次开发中的设备使用反馈，不是正式用户研究，也不代表某项完整流程已经通过。站姿或坐姿、控制器校准、双眼对齐及完整复现顺序尚未形成记录。日志中的 OpenXR 错误出现于启动或退出附近，不能据此认定持续卡顿的唯一原因。

## 问题依据与当前修订

**移动碰撞。** 原手代理的自定义扫掠会排除自身 XR Origin，但实际手掌与手套包络的 PhysX Collider 没有排除自身 `CharacterController`。手代理在世界空间跟随；移动发生时，上一帧的手代理可能阻挡自己的角色。修订按 Collider 对隔离手掌、包络与**同一 Origin 的角色胶囊**，保存原忽略状态，并在停用、销毁或重新绑定时恢复。环境墙面、桌面及其他角色的碰撞继续保留。左摇杆输入绑定、移动方向配置没有因本轮修改而改变；实际设备是否仍倒退或卡顿须另测。

**抓握位置。** 原持有可见手沿用手代理抓取时的相对偏移，五指趋向完整握拳；抓取转换器保留原物体偏移，未形成用户期望的贴附效果。修订新增 `MuseumGripSurface`，从当前启用模型的缓存三角形和实时变换计算最近表面点、朝向手的表面法线，再把可见手的掌面接触点朝该点对齐。缓存来源是现有 Unity 模型的只读网格数据；没有修改 FBX、模型导入器的 Read/Write 设置或历史模型 GUID。首次烘焙记录为 518 个模型 Filter、480 个不同网格、254,198 个三角形，最终资产与验证版本以下方记录为准。

**近距拿取与支撑姿势。** 本体的 Direct 可选范围改为固定张手包络外侧 **60 mm**，仍要求实心障碍视线检查；按钮、窗口及热点仍使用 **25 mm** 接触范围。热点只有实际接触时才优先阻止本体选择，单纯扩大范围后的悬停不再抢走本体。持有可见手使用 **0.4 支撑握姿**，避免大型壳体上的全握拳。第一只近距 Direct 手抓住本体时，物体可在约 **0.18 s** 内向掌面平滑收拢，位移上限 **12 cm**；Ray 不触发该辅助，`1→2→1` 换手按实际姿态重新建立基线，不重新吸附，尺度不变。XRI 继续独占展品刚体运动。

**设备诊断。** Development Player 新增本地 JSONL 观察，每约 0.15 s 记录实际左右移动动作、虚拟 Origin 位移、角色碰撞状态、手追踪与代理误差、持有目标、自身角色碰撞忽略状态及帧耗时。记录保存在 `Application.persistentDataPath/PhysicalHandsDiagnostics/`，不注入设备输入，不移动角色，不包含账号、网络地址或设备标识。诊断用于区分摇杆持续输入、碰撞阻挡与显示/帧耗时问题；采样文件本身不是通过报告。

## 限制与交接

当前仍是手套包络和五指预设动画，没有逐指碰撞、物体形状驱动的指节 IK 或真实力反馈。表面贴附改善可见掌面与模型的接触关系；粗略展品 Collider 仍承担物理碰撞。剖面显示裁切不等于产生新的可抓切面，未知或无法解析的网格会明确采用 Collider 回退。12 cm / 0.18 s、60 mm 及 0.4 支撑握姿属于待实机调整的原型参数，不能称为 Alyx 等效体验。

最近表面搜索的设备延迟、碰撞与双手边界行为、实际双眼手掌对齐、性能和完整展览流程仍需对应版本的验证。缓存烘焙成功或 Editor 编译通过分别只证明相应步骤，不证明抓握手感或移动问题已消失。

本轮继续使用 Unity **2022.3.62f3c1 / XRI 2.6.4 / Windows PC VR / OpenXR**，不升级依赖或迁移平台。共享头盔 Prefab 由单一整合人接入；原主目录及既有历史报告保留。新验证写入各自独立运行目录，故障日志和大量设备采样留本地，只提交有用证据。
