# 2026-10-17 照片头盔第二稿外观精修

关联：模型协作 [#25](https://github.com/Twispra/XRmuseum/issues/25)、第一稿 [PR #28](https://github.com/Twispra/XRmuseum/pull/28)。工作分支 `codex/photo-helmet-refinement-v2-2026-10-17`，起点 `00a8305`。本稿独立存放，未改第一稿和 Unity 场景。

本次根据小组提供的同一件实物前四张照片，检查第一稿正面与侧面展示效果，再把外壳色调、前窗与胸甲比例作为可比较的第二稿。修改由 Codex 辅助编写生成脚本、构建 GLB、回读几何并制作本地正面／侧面同投影对照；照片由小组提供作观察参考，未上传或当纹理使用。第一稿负责人 Fttt1003 的建模工作与本次增量保持区分。

遇到的限制：本机官方 Blender 4.5.14 的 GUI 启动后未能操作，命令行在 Metal 初始化时退出，因此没有生成或验证新的 `.blend`/FBX。采用独立 GLB 与可重建脚本保留工作结果，不把这一点写成 Blender/Unity 验证通过。下一步需由模型负责人在可运行的 Blender 环境中导入并人工核对前框、胸甲比例、UV 和材质，再考虑 Unity 接入与 VR 性能。

对照后的修正：上一轮尝试新增的铭牌和三颗胸甲紧固件未贴合原有胸甲，已撤掉；原第一稿已有空白铭牌，不应重复制作。照片中前窗相对盔壳较窄、胸甲可见深度较大，所以本稿将原前窗组件等比缩至 86%，胸甲从颈圈向下延伸（纵向系数 2.1）；保留原有侧窗格栅与背部附件，侧窗由近黑改为暖灰。以上仍是照片投影估计，不是实测。

本机验证：本次修订后 GLB 回读 110 个几何节点、117,304 个三角形、坐标有限；与第一稿作相同视角的软件投影对比，并对照照片 01–04。软件投影是几何／颜色检查，不是 Blender 或 Unity 渲染；没有实物测量、Unity、Player 或头显测试。见 `artifacts/helmet-refinement/photo-study-v2/qa/export-readback.json`。
