# 2026-10-18：照片头盔作为独立展品接入主场景

基于照片头盔 Unity 对比分支（PR #66），把现有照片参照模型放入 `MuseumStart.unity` 左侧空展台，作为独立的「1988 年潜水头盔外形研究」。1988 来自组员所拍展品说明牌；模型细节、尺寸和实际机构仍未核实。它不属于中央的 1839／Mark V／SuperLite 三年代列表，也不完成早期精细模型 [Issue #60](https://github.com/Twispra/XRmuseum/issues/60)。

## 本次改动

- 左展台放入已保存的 `PhotoHelmetStudy.prefab` 实例，旧占位编号隐藏；右侧展台与中央年代展品保持原样。
- 左展台增加独立的左转、复位、右转按钮，各次转动 30°；它们使用主场景现有的 XR Interaction Manager，不调用中央展品的 Reset 或年代切换。
- 展签和模型边界说明接入简体、繁体、英文语言表。展签写明「外形研究」「细节待确认」「不是实物复原」，没有为未核实的铰链、供气或通话添加动作。
- 为新按钮加上退出 Play 时的注销处理。隔离检查中，停用整件新展品或只停用三枚 XR 按钮均不会出现退出清理错误；修正后在完整启用状态下退出 Play 也无控制台错误。

## 检查结果与局限

使用 Unity **2022.3.62f3c1** 打开保存的主场景。Scene 视图从访客一侧检查模型、按钮和展签可读性；Play 模式中运行 `Museum > Photo helmet > Validate independent exhibit (Play Mode)`，通过模型、三枚按钮碰撞体和管理器绑定、左右转动及复位、三语展签、中央年代不变等定向断言。检查后退出 Play，控制台显示 0 错误。本次未用真实头显按按钮，未完成双眼可读性、触达舒适度、完整参观旅程、性能或可执行构建测试。

这是用于小组审阅的候选接入。左展台最终用途与 [Issue #64](https://github.com/Twispra/XRmuseum/issues/64) 有关，应在 PR 中确认；不能把这次编辑器检查称为组员实机验收。照片来自组员，模型和接入过程使用 AI 辅助；个人课程短文应按各人实际工作及 Git 提交记录填写，不把辅助检查写成独立人工贡献。
