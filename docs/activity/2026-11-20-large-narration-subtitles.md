# 2026-11-20 旁白字幕大字模式

展台的「设置」增加了「标准字幕／大字字幕」切换，适用于操作说明、供气和双向通话三段旁白。默认使用标准字幕，放大后以固定字号换行。字幕框保留原来的宽度和上沿，底板随文字行数向下展开，给台面控制和「显示面板」留出位置。

切换字号立即更新正在显示的字幕，保留语音进度和静音状态。设置保留至当前场景结束，打开新场景时回到标准字幕。静音访客也可先选大字，再用「播放语音」显示字幕。

以 `origin/main@5ddaab5` 为基线，分支为 `codex/large-narration-subtitles`。沿用现有实体站的松手确认、语言通道、字幕和底板，只增加字幕排版和设置。两条按钮文案同步到简体、繁体、英文和保存的本地化表，现有 Noto Sans SC 图集补入「幕」。没有修改音轨、场景、公共输入或工程设置。

Unity 编辑器验证覆盖实际射线切换、标准与大字恢复、三段三语布局、按钮投影及静音时播放。已保存报告、字体核对与标准／大字配对截图。[本次独立 QA](../../artifacts/helmet-interaction/qa/runs/20261120-large-narration-subtitles/README.md)

本项可独立运行。快捷导航 [PR #88](https://github.com/Twispra/XRmuseum/pull/88) 同时修改两份语言表、字符清单和 SDF 图集。先合并其中一份，再基于主线汇总两边的条目、重新生成字符清单和烘焙图集，复测受影响的三语功能。旁白音轨审校仍按 [Issue #63](https://github.com/Twispra/XRmuseum/issues/63) 进行。

Codex 辅助设置接入、三语文案、字体烘焙、Unity 验证及整理证据。组员可在 Unity Play Mode 中先打开「设置」切换，再播放任一段旁白，后续有设备时复核双眼可读性和触达。
