# 2026-11-20：展台快捷导航

基线是实际抓取的 `origin/main`：`5ddaab5a101a153a0d864e7765df31098f64bc49`，工作分支为 `codex/exhibit-quick-navigation`。开工工作区干净。本次对应明确选择的“展台快捷导航”改进，不代替 #77 的右侧展板接入，也不关闭其他 Issue。

## 完成的行为与取舍

加入左侧、中央、右侧三个观察位置，任一只手均可用射线按下并松开确认。Grip 与 Trigger 同时操作只算一次；按住移出取消。淡出至全黑再改变 XR Origin 的位置和水平朝向，过渡后恢复原有移动组件状态。到达前检查实体占位与地面，过渡中再次检查。

保留相机追踪局部姿态、当前眼高及视点高度偏移，保留语言、年代、模型姿态、发现和提示次数。调用原有站点的结束演示／讲解／手势接口；不把一次移动当成新访客或模型复位。“视角重置”会中止导航过渡，避免复位后又跳到先前选择的展台。

采用运行时安装，复用既有局部避障与跟随面板，不改主场景、公共 XR/Input Actions、Packages 或 ProjectSettings。编号识别允许左侧展台保留其 1988 年照片研究名称。新导航按钮只接受射线，避免实体近手操作前窗时抢占原有交互焦点。

八条三语文案维护在 JSON 和保存的 LocalizationTable 中，静态 SDF 由原字体补入“台、央、往”三个字形。字体、图集和材质身份保持；源 TTF 不变。功能和复跑方式见 [使用说明](../exhibit-navigation.zh-CN.md)。

## 验证与修正

使用 Unity `2022.3.62f3c1`，macOS / Apple M5 / Metal / Rosetta。独立报告、被测 commit、额外 dirty、进程退出状态、源码指纹与截图集中在 [本轮 QA](../../artifacts/helmet-interaction/qa/runs/20261120-exhibit-quick-navigation/README.md)。

开发过程中修正了旧展台名称识别、运行时 TMP 初始化顺序和英文两行按钮高度。合成 HMD 夹具扣除保存场景的 Device-origin floor offset，确保测试眼高是实际离地 1.2 米，而非再叠加一次成人身高。姿态夹具还覆盖 0.85、1.2、1.65 米及 1、2 倍缩放。

第一次年代回归在前窗射线悬停处失败；新导航允许近手悬停，会与原有控制器交互组竞争焦点。改为射线专用后，同一年代回归通过 1,131 项、进程退出 0。最终导航运行另行绑定修正后的版本，失败运行与完整日志保留本机输出目录，不把失败写成通过。

三语保存数据、现有语言输入／生命周期及年代／前窗交互分别验证。原语言回归的完整报告较大，仓库提交计数、错误、文件哈希摘要与无损压缩的完整报告，复跑入口沿用现有验证器。三语文字、黑场及实际场景画面有本次独立截图。
