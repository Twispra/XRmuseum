## 问题与修复

原 details OBJ 有 **70,888** 个顶点／法线和 **59,282** 个 UV；**18,159** 个面引用越界 UV，首例在展开后的第 **257208** 行，引用 UV **59289**。原因是源场景混合有 UV 和无 UV 的网格，trimesh 合并 OBJ 时三个索引流使用顶点偏移，但无 UV 网格没有输出对应的 `vt`。

导出器给 20 个无图像贴图的纯色 PBR 网格补 **11,606** 个中性 `(0, 0)` UV；已有 UV 和材质保留。若缺 UV 网格含 base-color、metallic-roughness、normal、occlusion 或 emissive 图像贴图，会拒绝导出。保存两份 OBJ 前检查全部 `v/vt/vn` 引用；也可通过不依赖第三方库的 `--validate` 模式复查已保存 OBJ。

重新导出后 details 有 **70,888** 个 `v/vt/vn`、**107,248** 个三角面；shell 有 **5,176** 个 `v/vt/vn`、**10,056** 个三角面，shell OBJ 字节未变。顶点坐标、数值法线、顶点／法线面拓扑、对象顺序、已有 UV、材质名称、贴图和源 GLB 均与修前一致。源 GLB 与组合 OBJ 的边界相符至 `1e-6`。
