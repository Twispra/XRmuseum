# 操作主面板：可隐藏、随时唤出、出现时朝向用户（草图 v1）

任务来源：[Issue #62](https://github.com/Twispra/XRmuseum/issues/62)。基准：`main` @ `7011f785`（含 PR #59）。
模块：`MuseumVR/Assets/Museum/Features/OperatorPanel/`。本文件是认领时承诺的「显示/隐藏状态草图 + 范围说明」，随首版 PR 一起评审。

## 范围草图：哪些可收起，哪些固定

```
                     ┌──────────────────────────────┐
   观察者眼睛 ───────▶│  唤出后的主面板（一次性摆放）  │
                     │  ┌──────────┐ ┌──────────┐  │
                     │  │ 设置面板  │ │ 模型说明  │  │
                     │  │ 三语/高度 │ │ 简化边界  │  │
                     │  │ 声音/动画 │ │          │  │
                     │  │ 提示/视角 │ │          │  │
                     │  └──────────┘ └──────────┘  │
                     └──────────────────────────────┘
                        ▲ 唤出时生成；之后固定在空间中，
                          转头/走近/调高度均不追随、不跳位

   展台（始终固定，不收起）：
   ┌───────────────────────────────────────────────┐
   │  [上一年代] [下一年代] [复位]                    │
   │  [提示]    [设置]     [说明]   ← 原有三键保留    │
   │  [面板]                       ← 新增唤出入口    │
   │  前窗入口(玻璃上)  供气  通话  关闭演示           │
   │  剖面图标 + 固定短轨道（展台左侧，不随模型转）     │
   └───────────────────────────────────────────────┘
```

- **可收起的主面板** = 现有「设置」（`Fixed settings`）与「模型说明」（`Fixed exhibit information`）两组内容。
- **固定入口** = 年代、复位、提示、前窗、剖面图标与滑轨、供气、通话、关闭演示，全部维持原位。
- **新增固定入口** = 展台上的「面板」按钮：面板收起时它是唯一唤出入口（单手射线可达，沿用现有 G 松开确认）；面板显示时再点即收起。设置／说明两个原有按钮仍可独立开关对应内容，打开时同样按下面的摆放规则落到眼前，行为一致。
- **不收进面板** 的就地操作（外壳旋转、前窗开合、供气／通话演示、剖面）完全不动；收起主面板也不会关闭正在阅读的讲解卡。

## 唤出与收起规则

| 状态 | 行为 |
| --- | --- |
| 唤出（按「面板」/「设置」/「说明」） | 以**当时**的观察者位置为准：面板出现在眼前约 0.65 m、高度略低于视线（默认低 0.06 m），**仅水平朝向**观察者（不随俯仰抬头/低头）。摆放一次后固定。 |
| 避让 | 摆放位置与头盔展品中心保持至少 0.55 m 水平距离（不足时沿侧向推开），避开头盔与展台固定按钮；避免长时间压住讲解卡。 |
| 显示中 | 转头、走近、用设置调高度，面板**不追随、不跳位**；再次主动唤出才按新视角重新摆放。 |
| 收起 | 面板整体隐藏；碰撞体随对象停用，**不再挡射线**。不重置头盔角度、剖面、年代、演示、语言、声音、减少动画、提示偏好，也不关闭讲解卡。 |
| 拖动中唤出／收起 | **明确拒绝**（无任何界面跳动）。本体／剖面拖动由控制器直接拒绝；设备拖动期间 station 的 XRI 过滤本就会阻止本入口被确认，行为一致。 |

以上 0.65 m / 0.06 m / 0.55 m 均为可调原型参数（Inspector 序列化字段），不是人体工学实测值。

## 实现要点

- 新模块**不修改** `DiegeticUI` 任何文件：状态唯一来源是 station 的公开状态（`SettingsVisible` / `AboutVisible`）；唤出入口复用 `HelmetPhysicalControl`（按下反馈、松手确认、移开取消、接近显现、延迟渐隐与 station 各按钮同一套规则）。
- 场景改动 = station 上的一个 `OperatorPanelController` 组件（含 station／viewer／材质引用）；唤出按钮与面板摆放全部**运行时构建**，不往共享场景里塞对象。卸载 = 删组件。
- 新增访客文字 3 条已登记 `MuseumTranslations.json`（`operator.panel.show/hide/hint`）；字形由字体烘焙流程补齐，验收脚本会逐字符核对保存字体的字符表。
