# 参与者信息页与知情同意（Participant Information & Consent）

> 用途：Phase 3 评价开始时逐条读给对方，口头确认后开始。
> 不采集签名以外的个人身份信息；如需书面同意，只保留一份纸质件，**不扫描上传、不进 Git**。

## 一、参与者信息页（研究者宣读）

**研究题目 / Study title**
COMP5424 Extended Reality 小组项目：可访问的博物馆 VR 体验的形成性评价
*Formative evaluation of an accessible museum VR experience*

**这是谁做的 / Who is running this**
香港理工大学 COMP5424 课程 group2 小组成员。本评价是课程作业的一部分，不涉及商业用途。

**为什么做 / Purpose**
我们在做一个虚拟海事博物馆：访客戴上头盔，观看三顶不同年代的头盔，可以切换年代、查看说明、听讲解。
我们想知道：**说明文字好不好读、状态好不好分辨、操作会不会卡住**，以便在下一版改进。

**会做什么 / What you will do**
- 戴 VR 头显（坐姿），按我们给的几个小任务自由操作，大约 **45–60 分钟**。
- 请你**边做边说出你在想什么**（think-aloud）。说得断断续续也没关系，不用组织语言。
- 最后有 10 分钟聊聊你的感受。

**可能的不适 / Possible discomfort**
VR 可能引起头晕、眼疲劳或恶心。**任何不适请立刻说"停"**，我们会立即帮你摘下头显并休息；
这不会影响任何事情，也不需要解释原因。你可以随时终止，无需给理由。

**数据怎么处理 / Data handling**
- 只记录：任务相关的操作屏幕录像/音频、观察笔记、你的口头反馈。
- **不采集**姓名、学号、联系方式、人脸影像。
- 转写时用代号（P1、P2…）替换，删除可识别的细节。
- 原始录音/录像只保存在项目组受控位置，**不上传公开仓库**；报告中只引用匿名摘录。
- 课程结束后 3 个月内删除原始音视频，仅保留匿名转写与编码结果。

**自愿与退出 / Voluntary participation**
参加完全自愿。你可以跳过任何问题、随时退出，不需要说明理由，不会有任何不利后果。

**联系 / Contact**
如有疑问，可联系本次评价的组内负责人（见本目录 [README](README.md) 的分工登记表）。

## 二、口头同意脚本（逐条确认）

主持人逐条读出，参与者口头回答"是/否"，主持人在观察表首页记录（不记姓名，只记 P 编号与日期）：

1. 你已阅读/听我读完上面的信息，并且有机会提问。 —— 是 / 否
2. 你理解参加是自愿的，可以随时退出且无需理由。 —— 是 / 否
3. 你理解 VR 可能引起不适，并会在不适时立即告知我们。 —— 是 / 否
4. 你同意我们记录**任务相关的屏幕录像与音频**用于分析。 —— 是 / 否
5. 你同意我们在报告中**匿名引用**你的原话摘录（如"这个字太小了"）。 —— 是 / 否
6. （可选）你同意我们在内部演示中使用**打码后的截图**。 —— 是 / 否

> 任一项为"否"时的处理：第 1–3 项为否则不开始；第 4 项为否时只做笔记不录音；
> 第 5 项为否时只做统计性描述、不引用原话；第 6 项为否不影响参加。

## 四、给主持人的三条纪律

1. **不引导**：不说"你点那个蓝色的点"，只说"你想怎么做就怎么做"。
2. **不辩护**：参与者说"这里很糟"时，回答"能多说一点吗"，不要解释设计意图。
3. **不代操作**：除非卡住超过 90 秒且属一级提示，否则不碰控制器、不替对方转头。
