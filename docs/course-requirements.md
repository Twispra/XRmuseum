## 哪些只是本组建议

Issue 认领、PR 审查、AGENTS、单人整合共享场景、运行目录和活动文件命名是本仓库为六人协作制定的工作方式，不是课程强制格式。没有官方要求每日提交、固定 commit 数、固定六人分工或每人必须开发一个完整展品。

`project-resource/小组方案（假设）/` 不是官方需求，也不是已达成共识的分工或真实成果。方向改变时在任务/PR 中说明依据，再更新状态页；不要从假设方案复制“已完成”或成员贡献。
