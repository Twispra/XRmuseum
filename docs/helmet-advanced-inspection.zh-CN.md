# 近距离观察与可调剖面

本功能在原 `MuseumStart` 展厅改进操作方式，位于 `codex/helmet-inspection-2026-09-29` 分支，尚未合入主线。没有换 XR 摄像头，也没有改共享输入映射、平台或原头盔模型。接手版本、回归证据和合并注意事项见[小组交接](helmet-inspection-handoff.zh-CN.md)。

## 先试这条流程

1. 按 Play。展品旁出现个人观察面板；走近或绕到另一侧后，它会重新找一个邻近位置。先用射线指向 **FLOAT** 并握持一下。
2. 握住头盔本体，拿近、抬起、向任意方向转动。松开后头盔停在这个姿态，方便同一只手继续操作。再次点 FLOAT 恢复普通物理；**RESET** 直接回展台。
3. 点击 **SECTION**。继续点击 **ALIGN VIEW**，切面会朝向你现在观察的方向，移除靠你的一侧。设置后它随头盔移动，不会随着每次转头自行改变。
4. 点击 **EDIT CUT** 显示青色边框和球形握柄。握住球柄，平移手改变切入深度，转动手腕改变切面角度；松开即保留。不必同时拿着头盔和工具。再点 EDIT CUT 隐藏辅助线，保留剖面。
5. 用 **DEEPER / SHALLOWER** 小步改变深度，**TOP CUT** 从顶部开始，**FLIP CUT** 换看平面的另一侧。也可抓整盔继续观察，或用 TURN / TILT 按钮转动。
6. **SECTION** 关闭剖面；**RESET / Home** 同时恢复展台位置、完整外壳、关闭前窗、隐藏工具和普通物理。

操作沿用一套规则：近处直接握持，远处射线指向后握持。在官方电脑模拟器中，Game 获得焦点后，Y 选右手，鼠标调整方向（R 切换 Rotate/Translate），G 是握持。调工具时需要保持 G，移动模拟手柄或转动它；松 G 固定剖面。没有新增摇杆快捷键，避免与移动、传送和原抓取锚点功能冲突。

## 为什么面板这样移动

面板只跟随位置与大幅转身，不跟着每一次低头、抬头和视线移动。它会延迟到访客移动稳定后再调整；射线瞄准、选择按钮或抓取头盔/前窗/剖切工具时暂停跟随。低头看细节时，按钮不会追着视线跑。

放置前会检查展台等静态碰撞体和头盔本身的碰撞范围，优先选择侧前方空位。剖面关闭时只按收起后的菜单高度检查，避免把已经隐藏的按钮算成障碍、将整块菜单抬到眼睛上方；展开后等待用户停止瞄准/选择，再根据实际大小调整位置。空间拥挤、所有候选位置被挡住时保留上一个位置；这仍需在最终展厅和真实设备中检查。**FLOAT 的顺序是先开启、再拿起、松手后调切面**，不要求双手配合。

## 仍需分清的边界

- 当前是空心灰模的观察工具，没有增加未经史料支持的内部设备。剖面边框、悬停、角度与深度限制是教学交互设计，不是历史头盔的实测性能。
- 剖面改变显示，原物理碰撞包络保留。因此不是切割模拟，不能据此把手伸进被隐藏的外壳操作内部零件。
- 悬停模式关闭后，物体会重新受重力影响；可以直接 RESET 安全回展台。任意轴 TILT 会自动开启悬停，避免刚倾斜就倒下。
- 自动 XR 输入、静态渲染和真实头显体验不是同一种证据。实机双眼显示、触达距离、菜单大小、舒适性与真实用户评价仍待设备检查。本轮结果见[活动记录](activity/2026-09-29-advanced-inspection.md)。
